# Project & Agent Instructions

## 1. Grounding & Reference Material

- Always check and reference the documents, PDFs, and notes located in the `/docs` (or reference) folder before
  proposing architectures or writing code.
- Ensure all implementations align strictly with the specifications in the provided project documentation.

## 2. Communication & Explanation Style

- **Target Audience:** Intermediate programmer (comfortable with Python syntax, core concepts, and reading code, but
  still mastering end-to-end architecture, advanced design patterns, and complex algorithms).
- **Thorough Explanations:** Do not just output code or brief summaries. Explain *why* a solution was chosen and *how*
  it works step-by-step.
- **Conceptual Clarity:** Break down non-trivial logic, external libraries, and data flow so the user understands every
  moving part completely, even if they wouldn't write it from scratch on their own.
- **Clarity over Jargon:** When introducing advanced patterns, explain the intuition behind them clearly.

## 3. Coding Practices

- Write clean, readable Python with descriptive variable names and clear docstrings.
- Add inline comments above complex logic explaining the reasoning behind specific steps.
- Prioritize maintainability and readability.
